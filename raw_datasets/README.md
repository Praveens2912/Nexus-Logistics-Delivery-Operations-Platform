# Raw Datasets

This folder contains the source datasets used in the Nexus Logistics & Delivery Operations Platform project.

## Datasets

The project works with seven logistics datasets:

1. Customers
2. Drivers
3. Hubs
4. Shipments
5. Shipment Events
6. Delivery Attempts
7. Invoices

## Purpose

These datasets serve as the source data for practicing data ingestion, data profiling, data quality validation and transformation using Snowflake SQL.

## Data Handling

The original source data should remain unchanged during processing.

Only datasets that have been checked for sensitive information should be published in this public repository.
